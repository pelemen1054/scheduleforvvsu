# ВВГУ — Расписание v1.3

Добавлен режим расписания преподавателя.

Поддерживается:
- имя преподавателя;
- публичная страница его расписания ВВГУ;
- время;
- дисциплина;
- форма занятия: Лекция / Практика / Семинар / Лабораторная / Экзамен / Мероприятие;
- аудитория;
- группа или группы студентов.

Публичные страницы ВВГУ в `portfolio.vvsu.ru/timetable/` подтверждают такую структуру данных.
Например, страницы преподавателей содержат колонки «День недели», «Время», «Дисциплина»,
«Форма занятия», «Аудитория», «Группа».

Следующий технический шаг — сделать автоматический поиск преподавателя и его `tid`, чтобы
пользователю не приходилось вставлять ссылку вручную, а также привязать даты секций таблицы
к выбранной дате календаря.
