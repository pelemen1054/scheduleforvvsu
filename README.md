# ВВГУ timetable

Android-приложение для просмотра расписания ВВГУ. Можно искать расписание своей группы или преподавателя, переключать даты и настраивать напоминания о занятиях.

> Проект независимый и не является официальным приложением университета. Проверяйте изменения аудиторий, переносы и экзамены по официальным источникам ВВГУ.

## Скачать приложение

**[Открыть сборки APK в GitHub Actions](https://github.com/pelemen1054/scheduleforvvsu/actions/workflows/build.yml)**

Как скачать последнюю сборку:

1. Откройте страницу сборок по ссылке выше.
2. Выберите самый свежий успешный запуск **Build Android APK**.
3. В разделе **Artifacts** скачайте архив с названием вида `VVSU_timetable_vномер`.
4. Распакуйте архив — внутри будет `VVSU_timetable.apk`.
5. Откройте APK на Android-устройстве и подтвердите установку, если система запросит разрешение.

Если сборка завершилась ошибкой, выберите более ранний успешный запуск. GitHub Actions хранит артефакты сборок ограниченное время.

## Возможности

- Расписание по учебной группе.
- Расписание преподавателя по публичным данным ВВГУ.
- Поиск и подсказки для выбора группы или преподавателя.
- Переключение даты, календарь и быстрый переход к сегодняшнему дню.
- Обновление расписания жестом или кнопкой.
- Локальный кэш расписания, чтобы недавно загруженные данные были доступны повторно.
- Избранные группы.
- Светлая и тёмная темы, выбор акцентного цвета.
- Уведомления о предстоящих занятиях с настройкой времени напоминания.
- Настройки и ссылки на ресурсы проекта внутри приложения.

Некоторые функции требуют подключения к интернету. Доступность расписания зависит от публичных страниц ВВГУ и их структуры. Для уведомлений разрешите приложению отправлять уведомления в настройках Android.

## Требования

- Android 8.0 (API 26) или новее.
- Интернет для загрузки актуального расписания.

## Сборка из исходного кода

Проект собирается в GitHub Actions при каждом push в ветку `main` или `master`. Используется JDK 17 и Gradle 8.13. APK создаётся задачей:

```bash
gradle :app:assembleDebug --no-daemon
```

Готовый файл появляется в артефактах соответствующего запуска GitHub Actions.
