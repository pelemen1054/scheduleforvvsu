# ВВГУ timetable

Удобное Android-приложение для просмотра расписания ВВГУ. Выбирай свою группу или преподавателя, смотри занятия на нужную дату и настраивай напоминания, чтобы ничего не пропустить.

## ✨ Что умеет приложение?

- **Расписание групп и преподавателей** — быстро находи нужные занятия.
- **Удобный поиск** — подсказки помогут выбрать группу или преподавателя.
- **Календарь** — переходи к нужной дате или возвращайся к сегодняшнему дню одним нажатием.
- **Избранные группы** — сохраняй нужные группы для быстрого доступа.
- **Обновление расписания** — загружай актуальные данные, когда это необходимо.
- **Локальный кэш** — недавно загруженное расписание может оставаться доступным без повторной загрузки.
- **Напоминания о занятиях** — настраивай уведомления и время их получения.
- **Настройка оформления** — выбирай светлую или тёмную тему и подходящий акцентный цвет.
