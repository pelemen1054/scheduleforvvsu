# Журнал изменений

## [1.0.9] — 21 октября 2026

- Добавлен бета-режим выбора языка интерфейса: русский, английский и китайский; перевод будет расширяться в следующих версиях.
- В настройки добавлена ссылка на Telegram-канал проекта.
- Название приложения изменено на «ВВГУ Timetable».
- Улучшена настройка сборки для сохранения совместимой подписи APK.


## [1.0.8] — 15 октября 2026

- Исправлено применение акцентного цвета к тексту и состояниям кнопок.
- Переключатели теперь используют выбранный акцентный цвет.
- В настройках появляется уведомление, если на GitHub опубликована версия новее установленной.
- Добавлена проверка последнего релиза GitHub при запуске приложения.

## [1.0.7] — 15 октября 2026

- Карточки расписания стали компактнее: краткая информация отображается сразу, полная — по нажатию.
- Добавлено раскрытие и сворачивание подробностей пары.
- Акцентный цвет применяется к текстовым акцентам, стрелкам и элементам управления Material Design.
- Исправлена ошибка компиляции Kotlin в импортах криптографических классов.
- Сохранена существующая схема подписи сборок.

## [1.0.6]

- Предыдущая опубликованная версия.
